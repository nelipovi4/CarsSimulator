# Driving Simulator

Реалистичный симулятор вождения по типичному городскому микрорайону, где вы становитесь водителем обычной машины и учитесь или оттачиваете навыки езды по правилам дорожного движения.

## 📝 Описание

Исследуйте уютные дворы, парковки и подъезды, соблюдая все нюансы ПДД: от светофоров и знаков до использования поворотников и правильного паркования. Игра сочетает расслабленный геймплей с элементами обучения, позволяя наслаждаться процессом без спешки гонок — просто чистое удовольствие от реалистичного вождения.

## ✨ Основные возможности

- 🚗 Реалистичная физика вождения
- 🏙️ Детализированный городской микрорайон
- 🚦 Полное соблюдение ПДД (светофоры, знаки, разметка)
- 👥 Мультиплеер до 4 игроков
- 🎮 Одиночный и сетевой режимы
- 🌙 Система освещения (фары, поворотники)
- 🎥 Несколько вариантов камер

## 💻 Системные требования

### Минимальные
- **ОС:** Windows 10 (64-bit)
- **Процессор:** Intel Core i3 4-го поколения или эквивалент
- **ОЗУ:** 4 ГБ RAM
- **Видеокарта:** Интегрированная графика (Intel HD 4000)
- **DirectX:** Версия 11
- **Место на диске:** 4 ГБ свободного места

### Рекомендуемые
- **ОС:** Windows 10/11 (64-bit)
- **Процессор:** Intel Core i5 8-го поколения или эквивалент
- **ОЗУ:** 8 ГБ RAM
- **Видеокарта:** NVIDIA GeForce GTX 1050 / AMD Radeon RX 560 (2 ГБ VRAM)
- **DirectX:** Версия 12
- **Место на диске:** 4 ГБ свободного места

## 🎮 Управление

| Клавиша | Действие | Примечание |
|---------|----------|------------|
| W / ↑ | Движение вперёд | Разгон машины |
| S / ↓ | Движение назад | Тормоз и задний ход |
| A / ← | Поворот влево | - |
| D / → | Поворот вправо | - |
| SPACE | Ручной тормоз | Дрифт |
| E | Правый поворотник | Вкл/выкл |
| Q | Левый поворотник | Вкл/выкл |
| K | Ближний свет фар | Включить |
| G | Ближний свет фар | Выключить |
| C | Переключение камер | Разные виды |

## 🚀 Режимы игры

### Одиночная игра
Свободное вождение по микрорайону с соблюдением ПДД. Нажмите "Одиночная игра" в главном меню для старта.

### Сетевой режим
Мультиплеер до 4 игроков:
- **Создать комнату:** Укажите название и создайте свою игру
- **Присоединиться:** Введите название существующей комнаты

## 🛠️ Технические детали (для разработчиков)

### Требования для разработки
- Unity 2020.3 или выше
- Visual Studio 2019/2022 или Rider

### Структура проекта
```
Assets/
├── Map/              # Префабы карты
├── Scenes/Scripts    # Логика игры
├── Scenes/           # Игровые сцены
├── Prefabs/          # Префабы (машины, знаки)
├── Resources/        # Материалы и текстуры
├── Models/           # 3D модели
└── Interface/        # Интерфейс пользователя
```

### Сборка проекта
1. Откройте проект в Unity Hub
2. Откройте сцену `Assets/Scenes/Menu_Scene`
3. File → Build Settings → Build
